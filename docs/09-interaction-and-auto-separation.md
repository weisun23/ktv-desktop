# 交互完善、自动分离、曲库在线更新

**日期**：2026-09-22

## 1. 交互完善（对应上一轮遗留的三项）

### 1.1 歌单选择弹窗（替换 window.prompt）

原来加入歌单是 `window.prompt` 让用户**输序号**，很别扭。现在改成正经弹窗
（`PlaylistPicker.vue`）：

- 列出所有歌单 + 每首歌单已有多少首
- **已在歌单里的会标出来**，避免重复添加
- 底部可直接输入新歌单名，回车即"新建并加入"
- 支持键盘：↑↓ 选择、Enter 确认、Esc 关闭

### 1.2 右键菜单键盘导航

KTV 常配遥控器，不能只靠鼠标。`ContextMenu.vue` 现在：

| 按键 | 行为 |
|---|---|
| ↑ / ↓ | 移动高亮，**自动跳过禁用项** |
| Enter / 空格 | 执行当前项 |
| Esc | 关闭 |

菜单打开时会自动获取焦点，鼠标悬停也会同步高亮位置。

### 1.3 控制条响应式（不再换行）

原来窄窗口下控制条会**换行成两行**，把画面顶上去。改成**按宽度分级隐藏次要控件**。

> ⚠️ **后续修正（重要）**：第一版把「快进/快退」和「音量」放在最低优先级、窄一点就直接隐藏，
> 结果用户的第一反应是**「声音控制、快进快退都缺失了」** —— 这两个恰恰是唱歌时随时要动的。
> 现在改成**只压缩形态、不删功能**（快进快退从「«5s」变 ⏪/⏩，音量滑块 92px → 56px），
> 这两样**任何宽度都保留**。详见 [docs/29](29-vocal-switch-and-stream-cache.md)。

当前规则：

| 宽度（控制条自身） | 显示 |
|---|---|
| ≥950px | 全部 |
| ≥730px | 隐藏「立体声」（音轨型片源用不到） |
| ≥570px | 再隐藏 变调（`[` `]` 快捷键仍在） |
| <570px | 再隐藏 全屏（F 键仍在） |

**播放/暂停、切歌、进度、音量、跳 5 秒、原伴唱 这六样任何宽度都保留。**

用 `ResizeObserver` 量控制条自身宽度，而不是窗口宽度——因为左栏宽度取决于窗口
和右栏的分配比例，只看窗口宽度会算错。

## 2. 播放时自动分离

原来分离要手动点按钮。现在：

```
片源就绪（本地文件）
  -> 已有伴奏文件？直接用，提示"可切伴唱"
  -> 没有且开启了分离？后台自动分离（不阻塞播放）
  -> 分离完成 -> 提示"伴奏分离完成，可切到伴唱"
```

在线流会跳过自动分离——分离器只认本地文件，要等它缓存到本地。

### 双文件切换

分离出的伴奏是一个**独立文件**，不是音轨。所以切「伴唱」时走的是**换文件**：

```
记录当前位置 -> 载入伴奏文件 -> 恢复播放 -> seek 回原位置
```

这条路径只在「有分离伴奏」时启用；自带双音轨/左右声道的 KTV 片源仍走原来的
切音轨/切声道，互不干扰。

## 3. 曲库在线更新

设置页新增「曲库」分组：

- **检查更新**：拉取远端 manifest（只读，不下载分片），比对本地 `db_version.txt`
- **下载并安装**：分片下载 -> 校验 md5/sha256 -> 原子替换，带进度条
- 更新完成后提示重启应用生效

清单地址用的是 maidong 公开仓库的 raw 链接（不需要凭证）：

```
https://gitee.com/yangyachao-X/maidong-ktv/raw/master/database_publish/database/manifest.json
```

这也是第 3 节「在线搜歌」调研后的建议路径：**新歌通过更新曲库进来**，
用的是同一个服务、同一套播放链路，最稳。

## 4. 修掉的两个健壮性问题

做设置弹窗的渲染验证时（用 Electron 直接加载页面、不走 preload），暴露了：

1. **设置为空时界面显示 NaN** —— `undefined / 1000` = NaN。
   现在 `SettingsDialog` 有一份 `DEFAULTS`，加载前先用默认值渲染。
2. **降级 bridge 不完整** —— `CatalogBrowser` / `QueuePanel` 直接用 `window.ktv`，
   在非 Electron 环境下整页报错。现在都补了兜底对象。

> 这两个都是**只在异常路径下才出现**的问题。如果没做这次渲染验证，会一直潜伏到
> 某个 bridge 调用失败的场景才爆发。

## 6. 遗留

- 自动分离是"播到才分离"，不是"点了就预分离"。队列里排队的歌不会提前分离。
- 曲库更新完成后需要**手动重启**应用（数据库被曲库服务进程持有）。
- 在线搜歌仍未实现，见 `docs/08-settings-and-separation.md` §3。
