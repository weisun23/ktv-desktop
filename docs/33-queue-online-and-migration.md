# 33 · 点歌队列、在线源与曲库迁移补全

本轮处理用户集中反馈的队列交互、在线源、已唱管理和数据迁移问题。

## 1. 切歌与再唱

- 已点“切歌”在没有 waiting 条目时禁用，并给出可读提示。
- 已唱“再唱”改为“立即唱”语义：当前正在播则从头重播，否则插到当前之后立即播放。
- 右键菜单和列表操作统一新增“立即唱”。

## 2. 原唱 / 伴唱单按钮

原唱、伴唱不再同时显示两个按钮，改成单个切换按钮：

- 当前原唱 → 显示“原唱”，点击切伴唱；
- 当前伴唱 → 显示“伴唱”，点击切原唱。

## 3. 头像与已唱删除

- 已点、已唱、收藏、歌单歌曲列表增加封面 / 渐变头像。
- 封面服务复用曲库列表的缓存逻辑。
- 已唱行增加删除按钮：
  - 正在播放的歌禁止删除；
  - 删除时先查曲库 filename，再删除本地缓存文件；
  - 最后移除已唱记录。

## 4. 在线点歌队列

在线搜歌和在线 MV 不再双击直接播放：

- 双击 = 加入已点；
- 行内和右键提供“立即唱”；
- 在线队列使用 `online:<platform>:<id>` 合成 id；
- 队列条目保存 platform / platformId / mvId / cover / duration / artist / title；
- 播放下一首时统一走 `resolveOnlineAndPlay()`。

## 5. 在线 MV 伴唱兜底

在线 MV 通常只有一条立体声音轨。切伴唱时使用中置消除：

```text
pan=stereo|c0=c0-c1|c1=c1-c0
```

本地左右声道型片源仍使用原声道映射，不受影响。

## 6. 全屏自动隐藏控制栏

- 全屏后鼠标静止 3.2 秒隐藏底部控制栏；
- 主进程轮询光标位置，在原生视频窗口上移动鼠标也能重新唤醒；
- 按任意键或点击界面同样会显示控制栏。

## 7. 曲库迁移

设置页「数据位置」新增曲库迁移：

- 选择目标目录；
- 目标位置为 `<目标目录>\KTV Desktop\catalog\muse.db`；
- 先停止曲库服务，再复制数据库，复制后校验大小；
- 更新 `catalogDir` 设置并重启曲库服务；
- 成功后尝试删除旧 muse.db；失败则保留旧文件。

## 8. 顶栏

移除了顶栏底部那条播放进度线。

## 9. 验证

- `npm run build:web`：通过；
- `npm test`：全量通过；
- Electron 冒烟连续通过；
- 在线队列实测：加入两首、连续切歌、在线 MV 立即唱均正常；
- 全屏实测：静止后控制栏 `display:none`，Esc 退出全屏正常。
