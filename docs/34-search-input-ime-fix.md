# 搜索框输入法修复（0.4.4）

## 现象

麦动曲库和在线源搜索框在 Windows 上无法正常输入，中文输入法候选框可能出现但文字无法提交。

## 原因

全局样式对 `body` 设置了 `user-select: none`，搜索输入框继承了该属性；同时搜索框额外阻断了 `keydown` 传播。Electron 33 + Windows 输入法组合下，这会让输入焦点和组合文本提交变得不可靠。

## 修复

- 为 `input`、`textarea`、`contenteditable` 显式恢复 `user-select: text`。
- 搜索框改为标准 `type="text"`，保留 `inputmode="search"` 和回车搜索。
- 移除搜索框上的 `keydown.stop`，由全局快捷键处理器统一忽略输入控件。
- 点击搜索框容器（包括搜索图标）时自动聚焦输入框。

## 验证

- 麦动搜索框：英文键盘输入、中文输入法组合输入均通过。
- 在线搜索框：英文键盘输入、中文输入法组合输入均通过。
- 输入后焦点保持，文字能正常提交。
