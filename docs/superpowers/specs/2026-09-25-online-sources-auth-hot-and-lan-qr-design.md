# 在线多平台账号、热门搜索与手机点歌入口设计

- 日期：2026-09-25
- 目标版本：0.5.0
- 状态：设计已确认，待用户审阅

## 1. 背景

当前在线源只实现网易云和酷我：

- 网易云提供歌曲搜索、MV 搜索和 MV 播放地址解析。
- 酷我提供歌曲搜索和音频播放地址解析。
- 原始 karaoke-companion 项目已经包含 QQ音乐、酷狗、咪咕、B站和 5sing 的实现方案。
- 2026-09-25 联网探测表明：QQ音乐、酷狗、咪咕的搜索和热门榜接口可用，但不登录时无法稳定取得播放地址；B站无需登录即可取得 720P 合并 MP4，但本次明确不接入。
- 手机点歌二维码目前只位于“设置 → 手机点歌”，入口过深，日常使用很难发现。

## 2. 目标

1. 接入 QQ音乐、酷狗、咪咕三个新的在线源。
2. 为需要登录的平台提供扫码登录和 Cookie 导入。
3. 在线搜索页在输入框为空时展示当前平台的热门内容。
4. 让手机扫码点歌成为显眼、常驻、可直接打开的入口。
5. 保持网易云、酷我现有搜索和播放行为不回归。

## 3. 非目标

- 本次不接入 B站。
- 本次不做跨平台“全部聚合”搜索；平台一次选择一个。
- 本次不做平台账号注册、付费会员购买或版权绕过。
- 本次不改变局域网手机点歌页的业务逻辑，只调整桌面端入口和展示方式。

## 4. 在线平台架构

### 4.1 平台注册表

在 ktv-api 中增加统一的平台注册表，平台标识固定为：

- netease
- kuwo
- qq
- kugou
- migu

每个平台适配器提供以下能力：

- search(keyword, page, pageSize)
- hot(page, pageSize)
- resolveAudio(id)
- resolveMv(mvId)（没有 MV 能力时返回 NOT_SUPPORTED）
- requiresAuth（布尔值）
- displayName

网易云和酷我保留现有实现；QQ音乐、酷狗、咪咕新增 Node 实现，接口结构参考原始 karaoke-companion 项目。

### 4.2 单平台搜索

在线搜索工具栏增加平台选择器：

网易云 / QQ音乐 / 酷狗 / 咪咕 / 酷我

每次搜索只请求一个平台。结果中显示平台标签和登录状态：

- 可播放
- 需要登录
- 当前平台暂不可用
- 该曲目没有可播放资源

不默认聚合多平台，避免超时、重复和来源混淆。后续如需“全部”模式，作为独立迭代实现。

## 5. 平台账号与凭证

### 5.1 登录方式

每个平台支持两种登录方式：

1. 扫码登录：打开官方网页登录窗口，用户用手机扫码。登录成功后从该平台的 Electron session 中读取 Cookie。
2. Cookie 导入：用户粘贴 Cookie 字符串。适用于官方扫码页面变化或无法扫码的场景。

QQ音乐、酷狗、咪咕都显示“扫码登录”按钮；如果扫码窗口无法完成登录，界面提供 Cookie 导入入口。

### 5.2 凭证存储

- 每个平台使用独立的 Electron session partition。
- Cookie 不返回渲染进程，渲染进程只能读取“是否已登录、更新时间、是否过期”。
- 使用 Electron safeStorage 加密 Cookie 后保存到数据目录的 platform-auth 文件。
- 如果系统不支持 safeStorage，则拒绝保存并显示可读错误，不静默降级为明文。
- 用户可在“平台账号”中单独退出登录或清除某个平台的凭证。

### 5.3 凭证失效处理

- 播放地址接口返回未登录、invalidq、Empty key、201007 等错误时，标记该平台为需要重新登录。
- 不自动删除 Cookie，避免临时风控导致用户反复登录。
- 条目仍保留在搜索结果中，点击播放时打开登录提示。

## 6. 播放地址解析

### 6.1 QQ音乐

- 搜索使用 musicu.fcg 搜索接口。
- 播放使用 vkey.GetVkeyServer 获取 purl，再拼接 sip 主机。
- 未登录或返回 invalidq 时返回 AUTH_REQUIRED。
- 如果歌曲返回 MV，则优先尝试 MV 地址；否则回退音频。

### 6.2 酷狗

- 搜索使用 mobilecdn 搜索接口。
- 播放优先使用移动端播放地址接口，失败时回退 play/getdata。
- Empty key、无 play_url、HTML 响应都归类为可读的播放失败。
- MV 地址只在接口明确返回可用 URL 时使用，否则走音频。

### 6.3 咪咕

- 搜索使用 search_all.do。
- 播放使用 listen-url/v2.4。
- code 201007 或其他非成功码返回 AUTH_REQUIRED 或 PLATFORM_UNAVAILABLE，界面按状态提示。
- MV 优先使用资源详情接口返回的 mvList/newMvList；没有可用 URL 时回退音频。

## 7. 热门内容

在线搜索页在输入框为空时显示当前平台的热门榜：

- 网易云：现有热歌榜接口。
- 酷我：现有排行榜接口。
- QQ音乐：ToplistInfoServer。
- 酷狗：排行榜接口。
- 咪咕：榜单内容接口。

展示规则：

- 显示排名、封面、歌名、歌手、时长、平台标签。
- 支持分页、点歌、立即唱、收藏。
- 需要登录的平台仍展示热门榜；点击播放时再触发登录提示。
- 搜索词非空时切换为搜索结果；清空输入框后恢复热门榜。
- 加载中、空结果、平台不可用分别使用独立状态，不互相伪装成“没有找到”。

## 8. 手机扫码点歌入口

### 8.1 顶栏常驻入口

在设置齿轮旁增加“手机点歌”按钮：

- 图标使用二维码或智能手机。
- 运行中显示绿色状态点。
- 未运行或已关闭显示灰色状态点。
- 点击打开“手机点歌”弹窗。

### 8.2 弹窗内容

弹窗包含：

- 当前状态：运行中 / 未启动 / 已关闭。
- 二维码。
- 手机访问 URL。
- 复制链接按钮。
- “手机需连接同一个 Wi-Fi”提示。
- 开启、关闭、修改端口的入口。
- 防火墙提示。

弹窗复用现有 bridge.lan.info() 和 /api/qr.svg，不新增二维码生成逻辑。

### 8.3 空闲画面入口

没有歌曲播放时，左侧视频占位区域显示“手机扫码点歌”卡片：

- 包含较小二维码和一句操作提示。
- 开始播放后自动隐藏，不遮挡视频。
- 全屏状态下不显示。

### 8.4 设置页定位

设置页继续保留手机点歌高级配置：

- 开启 / 关闭。
- 端口。
- 防火墙说明。
- 多网卡地址。

设置页不再是唯一的二维码入口。

## 9. IPC 与前端接口

新增或扩展的 IPC：

- online:sources：返回平台列表、显示名、是否需要登录。
- online:search：参数增加 platform。
- online:hot：按 platform 获取热门榜。
- auth:status：返回各平台登录状态。
- auth:openLogin：打开指定平台登录窗口。
- auth:importCookie：保存用户粘贴的 Cookie。
- auth:logout：清除指定平台凭证。
- lan:info：继续复用现有接口。

渲染进程不接触 Cookie 原文。平台账号页面只显示登录状态和操作按钮。

## 10. 错误与状态模型

统一返回以下状态：

- OK
- AUTH_REQUIRED
- AUTH_EXPIRED
- PLATFORM_UNAVAILABLE
- NO_PLAYABLE_RESOURCE
- NOT_SUPPORTED

前端映射：

- AUTH_REQUIRED / AUTH_EXPIRED：显示“需要登录”并打开平台账号。
- PLATFORM_UNAVAILABLE：显示“当前平台暂不可用”，不隐藏条目。
- NO_PLAYABLE_RESOURCE：显示“该曲目暂无可播放资源”。
- NOT_SUPPORTED：显示“该平台不支持此功能”。

## 11. 测试策略

### 11.1 单元测试

- 平台注册表和平台标识。
- 各平台搜索响应解析。
- 各平台热门榜响应解析。
- 播放地址解析的成功、未登录、无资源三类分支。
- safeStorage 凭证加密、读取、清除。
- IPC 通道完整性。
- 热门榜空搜索切换逻辑。

### 11.2 联网测试

- 网易云、酷我、QQ音乐、酷狗、咪咕搜索接口。
- 五个平台热门榜接口。
- 无凭证时 QQ音乐、酷狗、咪咕返回 AUTH_REQUIRED，而不是空结果。
- 有有效凭证时手工验证播放地址解析；凭证不进入自动化测试仓库。

### 11.3 UI 验证

- 顶栏手机点歌按钮的三种状态。
- 二维码弹窗打开、复制、开启/关闭和端口修改。
- 空闲画面二维码卡片显示与播放后隐藏。
- 在线搜索平台切换。
- 空搜索显示热门榜，输入关键词显示搜索结果。
- 未登录条目点击播放触发登录提示。

## 12. 发布与兼容

- 目标版本：0.5.0。
- 网易云和酷我现有行为保持兼容。
- 现有用户状态 schema 不因本功能强制升级。
- 平台凭证文件与 user-state.json 分离，避免状态文件膨胀。
- 未登录用户仍可使用网易云、酷我；QQ音乐、酷狗、咪咕可搜索和浏览热门榜，但播放前需要登录。
- 代码签名、SmartScreen 提示和局域网无鉴权说明保持不变。
