# 在线多平台账号、热门搜索与手机点歌入口

## 0.5.0 新增内容

- 在线源新增 QQ音乐、酷狗、咪咕。
- 三个新平台支持扫码登录和 Cookie 导入；Cookie 使用 Electron safeStorage 加密保存。
- 在线搜索页在输入框为空时显示当前平台的热门榜。
- 平台切换、登录状态和“需登录”标记直接显示在搜索结果中。
- 顶栏新增常驻「手机点歌」按钮，点击打开二维码弹窗。
- 没有歌曲播放时，左侧画面占位区域显示手机扫码点歌卡片。
- 设置页保留手机点歌的端口、开关和防火墙高级配置。

## 在线源说明

- 网易云：搜索、MV 搜索和 MV 播放。
- 酷我：搜索和音频播放。
- QQ音乐：搜索、热门榜；播放需要登录或 Cookie。
- 酷狗：搜索、热门榜；播放需要登录或 Cookie。
- 咪咕：搜索、热门榜；播放需要登录或 Cookie。
- B站本次明确不接入。

## 验证结果

- 五个平台的搜索和热门榜接口均可返回结果。
- 无凭证时 QQ音乐、酷狗、咪咕的播放解析返回 AUTH_REQUIRED，不会伪装成空结果。
- 平台凭证测试覆盖加密保存、读取、退出登录和安全存储不可用分支。
- 前端已验证平台切换、空搜索热门榜、登录提示、顶栏二维码和空闲画面二维码。

## 0.5.1 修复

- 设置页按钮补上当前选中态。
- 平台登录态优先从持久化 session 读取，安全存储文件作为兜底。
- 在线 MV 地址不可用时使用网易云 MV 回退，不再退化成纯音频。
- 在线伴唱使用部分中置衰减，避免完全静音。
- 搜歌和搜 MV 真正按 MV 标记过滤。

## 0.5.2 增强

- 设置页显示应用版本、Electron 版本和 Chromium 版本。
- 无 MV 的在线歌曲可播放音频，并显示音频占位和封面。
- 网易云无 MV 歌曲使用酷我音频补源。
- MV 失败时不回退为纯音频。
